# 📦 Shell & Environment

### 🐚 Category 15: Shell & Environment (Commands 163–175)

| # | Command | Short Definition (6–10 words) | Example |
|---|---|---|---|
| 163 | `echo` | Prints text or variable values to terminal. | `echo "Hello Linux"` |
| 164 | `printf` | Prints formatted output using specified format string. | `printf "%s\n" "Hello"` |
| 165 | `export` | Sets environment variables for current shell session. | `export JAVA_HOME=/usr/lib/jvm/java-21` |
| 166 | `unset` | Removes specified environment variable from current session. | `unset JAVA_HOME` |
| 167 | `env` | Displays or runs commands with custom environment. | `env` |
| 168 | `printenv` | Displays current environment variables and assigned values. | `printenv PATH` |
| 169 | `alias` | Creates shortcut for frequently used shell commands. | `alias ll='ls -la'` |
| 170 | `unalias` | Removes previously created shell command alias. | `unalias ll` |
| 171 | `source` | Reloads shell configuration without restarting terminal. | `source ~/.bashrc` |
| 172 | `history` | Displays previously executed shell commands chronologically. | `history` |
| 173 | `clear` | Clears previous output from terminal screen completely. | `clear` |
| 174 | `reset` | Resets terminal settings and clears corrupted display. | `reset` |
| 175 | `exit` | Terminates current shell session or terminal window. | `exit` |
