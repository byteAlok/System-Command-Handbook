# 📦 Chunk 4D (Commands 221–245)
### Docker Essentials

> **Note:**
> Docker isn't a built-in Linux command, but it's one of the most essential tools for modern Software Engineers, DevOps Engineers, Cloud Engineers, and Software Architects.

### 🐳 Category 18: Docker Essentials (Commands 221–245)

| # | Command | Short Definition (6–10 words) | Example |
|---|---|---|---|
| 221 | `docker version` | Displays Docker client and server version information. | `docker version` |
| 222 | `docker info` | Displays detailed Docker engine configuration and status. | `docker info` |
| 223 | `docker login` | Authenticates with Docker registry using credentials. | `docker login` |
| 224 | `docker logout` | Removes stored Docker registry authentication credentials. | `docker logout` |
| 225 | `docker search` | Searches Docker Hub for available container images. | `docker search nginx` |
| 226 | `docker pull` | Downloads container image from Docker registry. | `docker pull nginx` |
| 227 | `docker images` | Lists locally available Docker container images. | `docker images` |
| 228 | `docker build` | Builds Docker image from Dockerfile instructions. | `docker build -t myapp .` |
| 229 | `docker tag` | Assigns new name or tag to image. | `docker tag myapp:latest myapp:v1` |
| 230 | `docker push` | Uploads Docker image to remote registry. | `docker push username/myapp:v1` |
| 231 | `docker run` | Creates and starts new Docker container. | `docker run -d nginx` |
| 232 | `docker ps` | Lists currently running Docker containers only. | `docker ps` |
| 233 | `docker ps -a` | Lists all Docker containers including stopped ones. | `docker ps -a` |
| 234 | `docker exec` | Executes command inside running Docker container. | `docker exec -it web bash` |
| 235 | `docker logs` | Displays logs generated by Docker container. | `docker logs web` |
| 236 | `docker inspect` | Displays detailed metadata about Docker objects. | `docker inspect web` |
| 237 | `docker stop` | Stops running Docker container gracefully. | `docker stop web` |
| 238 | `docker start` | Starts previously stopped Docker container. | `docker start web` |
| 239 | `docker restart` | Restarts Docker container without manual intervention. | `docker restart web` |
| 240 | `docker rm` | Removes stopped Docker container permanently. | `docker rm web` |
| 241 | `docker rmi` | Removes unused Docker images from local storage. | `docker rmi nginx` |
| 242 | `docker network` | Creates, lists, and manages Docker networks. | `docker network ls` |
| 243 | `docker volume` | Creates and manages persistent Docker volumes. | `docker volume ls` |
| 244 | `docker compose` | Defines and runs multi-container Docker applications. | `docker compose up -d` |
| 245 | `docker system` | Manages Docker system resources and cleanup. | `docker system prune` |
