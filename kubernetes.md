# 📦 Chunk 4E (Commands 246–265)
### Kubernetes & Cloud Utilities

> **Note:**
> Kubernetes (`kubectl`), Helm, and utilities like `jq` / `yq` are not built into Linux, but they are essential tools for modern DevOps, Cloud, and Platform Engineers.

### ☸️ Category 19: Kubernetes & Cloud Utilities (Commands 246–265)

| # | Command | Short Definition (6–10 words) | Example |
|---|---|---|---|
| 246 | `kubectl config` | Manages Kubernetes cluster contexts and credentials. | `kubectl config get-contexts` |
| 247 | `kubectl get` | Lists Kubernetes resources from selected namespace. | `kubectl get pods` |
| 248 | `kubectl describe` | Displays detailed information about Kubernetes resources. | `kubectl describe pod nginx` |
| 249 | `kubectl apply` | Creates or updates resources from manifest files. | `kubectl apply -f deployment.yaml` |
| 250 | `kubectl delete` | Removes Kubernetes resources from current cluster. | `kubectl delete pod nginx` |
| 251 | `kubectl logs` | Displays logs generated by Kubernetes containers. | `kubectl logs nginx` |
| 252 | `kubectl exec` | Executes commands inside running Kubernetes containers. | `kubectl exec -it nginx -- bash` |
| 253 | `kubectl top` | Displays CPU and memory usage metrics. | `kubectl top pods` |
| 254 | `kubectl scale` | Changes replica count for Kubernetes workloads. | `kubectl scale deployment web --replicas=3` |
| 255 | `kubectl rollout` | Manages deployment rollouts and rollback operations. | `kubectl rollout status deployment/web` |
| 256 | `kubectl expose` | Creates Kubernetes Service for application access. | `kubectl expose deployment web --port=80` |
| 257 | `kubectl port-forward` | Forwards local ports to Kubernetes resources. | `kubectl port-forward pod/nginx 8080:80` |
| 258 | `kubectl edit` | Edits Kubernetes resources using default editor. | `kubectl edit deployment web` |
| 259 | `helm install` | Installs Kubernetes applications using Helm charts. | `helm install web nginx` |
| 260 | `helm upgrade` | Upgrades existing Helm release to newer version. | `helm upgrade web nginx` |
| 261 | `helm uninstall` | Removes Helm release from Kubernetes cluster. | `helm uninstall web` |
| 262 | `helm list` | Lists installed Helm releases in cluster. | `helm list` |
| 263 | `jq` | Processes and filters JSON data efficiently. | `kubectl get pods -o json \| jq '.items[].metadata.name'` |
| 264 | `yq` | Processes and edits YAML configuration files. | `yq '.spec.replicas' deployment.yaml` |
| 265 | `watch` | Continuously monitors changing Kubernetes command outputs. | `watch kubectl get pods` |
